# NMPARegHub v1.0.0 — 药品法规知识库

面向药品注册、药物警戒与药事管理的**本地法规检索与版本追踪**工具。
纯 Python 标准库，零第三方依赖，数据完全自持于一个 SQLite 文件。

## 本版本包含

**采集**
- 中国政府网政策文件库采集器（公开 JSON 检索接口 + 服务端渲染文章页解析）
- 国家药典委员会公告采集器
- 离线导入器：HTML / PDF / TXT / Markdown，支持整目录批量导入，保留来源路径

**检索**
- SQLite FTS5 `trigram` 全文索引
- 两字词自动回退 `LIKE`（trigram 对 <3 字的中文查询恒为 0 结果，这是必须处理的坑）
- 检索语法：`药品注册 -化妆品`（排除）、`"精确短语"`、多词隐式 AND
- 分面筛选：主题 / ICH / CTD / 发文机关 / 年份 / 效力状态

**结构化**
- ICH 指导原则自动归类（Q1–Q12、S1–S11、E1–E14、M1–M8）
- CTD 模块归类（模块 1–5、eCTD）
- 18 类主题分类，带标题级排除规则（避免「化妆品注册备案」被误归为「药品注册」）
- 发文字号归一化：`药监局公告2021年第32号` → `国药监〔2021〕32号`
- 发文机关名称归一化：`药监局` / `国家药监局` / `国家药品监督管理局` → 统一

**版本追踪**
- 正文变化时自动归档历史版本
- `unified diff` 输出，可定位到具体条款改动
- 效力状态保守推断（仅在正文尾部出现明确废止表述时标注）

**界面**
- 零依赖 Web 界面（`http.server`），支持分面筛选、文档阅读与版本 diff

## 合规说明（重要）

`nmpa.gov.cn`、`cde.org.cn`、`nhc.gov.cn` 均部署 JavaScript 反爬 WAF，
对普通 HTTP 客户端返回 412/202 与混淆挑战脚本。

**本项目不实现绕过该保护机制。** 这些机构的文件通过离线导入进入知识库 ——
用户在浏览器中正常打开并另存，再用 `import` 命令入库。

## 快速开始

```bash
git clone https://github.com/leerogerstheman/NMPARegHub
cd NMPARegHub

python regkb.py crawl                    # 采集中国政府网药品法规
python regkb.py import D:\我的法规资料     # 导入本地公告（HTML/PDF/TXT/MD）
python regkb.py search "药品注册 -化妆品"  # 检索
python regkb.py facets                   # 分面统计
python regkb.py diff 11                  # 比对版本
python webui.py                          # Web 界面 → http://127.0.0.1:8765
```

无需 `pip install`，Python 3.9+ 即可运行。

## 修复的关键缺陷

开发过程中由真实数据暴露并修复的三个缺陷，均有回归测试覆盖：

1. **纯排除查询静默返回 0 条** — `doc_number NOT LIKE ?` 在字段为 NULL 时结果为
   NULL，而 `NULL AND x` 永不为真，导致所有无发文字号的文件被静默丢弃。用
   `COALESCE` 包裹修复。
2. **FTS5 `NOT` 无法独立成立** — 排除条件改用 SQL 谓词实现，而非 FTS 的 `NOT`。
3. **分类子串误匹配** — 「化妆品注册备案」因含「注册」被误归为「药品注册」，
   引入标题级排除规则修复。
